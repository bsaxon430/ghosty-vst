How Ghost Lab uses CDP:
  - The CDP programs pvoc, stretch, strange, focus, blur, modify, combine, morph, repitch, formants, envel and cdparams (the parameter
    definitions CDP's own front end uses) are included as separate,
    unmodified executables (in each plug-in and app bundle: Contents/Helpers/cdp). Ghost Lab starts them like a user
    would from a terminal; Ghost Lab's own code does not contain or link any CDP code.
  - They were built from commit 28bc42c72c1a7cb0fab933acd1c433be958a787b of https://github.com/ComposersDesktop/CDP8
    (universal: arm64 + x86_64), with CMake as its building.txt describes (portaudio programs off).
  - You may replace these programs with your own build of CDP (same names, same folder) and Ghost Lab will use them.
  - CDP's complete source code for exactly this build is included (Licenses/CDP8-source.zip); see SOURCE-OFFER.txt.
