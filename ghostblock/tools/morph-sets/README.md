How the MORPH SETS (src/ghostblock/morph-sets.h) were made. Offline only, never shipped.
  render.cpp   renders a factory patch with the Six Sines engine alone (one C3 for 2 s, then release) to raw float
  p2sets.py    the sets (four factory sounds each, an OCTAVE per corner, ORBIT)
  p2verify.py  equal corner loudness (each corner's VOLUME), then the board's equal-power mix at a 5 x 5 grid of puck positions
