is a separate plug-in and is not changed by it.

The sound engine is Vital's open-source source code (https://github.com/mtytel/vital, commit 636ca0ef517a4db087a6a08a6a8a5e704e21f836),
copyright Matt Tytel, used under the GPL-3: the wavetable oscillators, filters, envelopes, LFOs, modulation, effects, the
.vital preset format and Vital's own full editor (the main SYNTH page). Ghosty Pro is not Vital and is not made or endorsed by
Vital Audio. Vital's own presets are not included.

Built with JUCE (GPL-3), as bundled with Vital, plus nlohmann/json (MIT), moodycamel ConcurrentQueue (BSD) and KISS FFT (BSD).
Fonts bundled with Vital's source: Lato, Montserrat, Roboto, Open Sans, Droid Sans Mono (Apache 2.0 / SIL OFL 1.1).

The knob physics (flywheel momentum with friction, magnetic detent spring, release-velocity tracking) is Ghosty Pro's own
code (ghosty/shared/GhostOrbit.h). Vital's knobs get it through marked UI-only edits in synth_slider.h/.cpp and its rotary
shader (shaders.cpp); Vital's sound engine is unchanged.

KEYS (build 5: ARPEGGIATOR, CHORDS, SCALE LOCK, HOLD): Ghosty Pro's own Performer code (from the earlier Ghosty Pro,
ghosty-pro/GhostyPro/Performer.h), ported to this build in ghosty/src/GhostyKeys.h. We first looked for a maintained,
GPL-compatible arpeggiator / chord / scale library to build on; LibreArp (GPL-3) and Arpligner are complete pattern-arp
plugins with their own editors rather than libraries, and neither has chords or scale lock. KEYS only changes the MIDI
notes Vital's engine receives; the sound is Vital's.
