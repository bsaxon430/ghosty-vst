# Old Ghosty Pro controls and what happened to them

Ghosty Pro 4 runs on Vital's engine, so the old engine's own controls are gone or are now Vital's versions.

## Kept (ours, rebuilt on Vital's controls)
- MORPH / SPIRIT BOARD: ghosts, puck, blend modes, ghost pull, snap, circle / figure 8 / random walk orbits, drawn path.
  New: GLIDE (ghost to ghost) and STEP (one ghost at a time), every motion tempo-locked 1/16 triplet .. 8 bars or free Hz.
- GHOST GATE and HAUNT (from the old FX rack; Vital has no version of them).
- The four looks: GHOST, BLACK, PURPLE, LIGHT.
- Presets by category, save / load, init, bypass; macros 1-4 (now Vital's macros, with names per preset).

## Now Vital's version (same job, Vital's sound)
- Oscillators, wavetables, DRAW / WAV import, warp modes -> Vital's oscillators and wavetable editor (SYNTH page).
- Filter (types, drive, envelope, key tracking) -> Vital's two filters and filter models.
- Envelopes, LFOs, mod matrix, velocity, mod wheel -> Vital's 6 envelopes, 8 LFOs, 4 random sources, modulation matrix.
- Glide / mono / legato, voices, bend range -> Vital's voice settings.
- FX rack units with a Vital equivalent: CHORUS, ECTO ECHO, SPECTRAL SPACE / SHIMMER / HAUNTED HALLS / DOORWAY (reverbs),
  DISTORTION / WRECKER / TUBE GLOW / SOUL CRUSH, SPIRIT EQ / TONE EQ, PHANTOM FILTER, COMPRESSOR / GHOST SQUEEZE (OTT),
  phaser and flanger -> Vital's chorus, delay, reverb, distortion, EQ, filter, compressor, phaser, flanger.

## Gone (not carried over)
- TRAP page (CHARACTER, TAPE / SLOWED, STACK and SAMPLE layers) and its presets: removed on Brandon's word ("it never worked").
  Trap-ready sounds are now Ghosty Pro presets (Velvet 808, Phonk Cowbell Bass, Trap Bell Pluck, Wobble Ghost ...).
- BEND page (the drawn tempo-synced pitch lane).
- The old extra oscillator engines (Plaits-style macro oscillators, TEXTURE, RESONATOR).
- PLAY strip extras: scale lock, one-finger chords, the arpeggiator, HOLD / FLOW keyboard.
- STUDIO layout (one front page) and the SNAPSHOT button (MORPH ghosts now hold snapshots of a sound).
- The macro map (one macro riding many settings with curves): Vital's macros do this through the modulation matrix.
- Old FX rack units with no Vital version and not yet ported: GHOST GRID, CRYSTAL, FATTEN, HYPER / DIMENSION, SPLITTER,
  RETRO, CRACKLE, BASS LAB, GHOST SPECTRA, GHOST LIMITER, the rack's scenes and timeline.
- CLEAN card and the per-preset loudness trim (levels now live in each preset's own volume knob).
