Install

Universal builds: Apple Silicon and Intel Macs, macOS 11 or newer.

1 · Paste one line

Open Terminal and paste this. It downloads every plugin, puts them in your VST3 folder and clears the macOS download block.

curl -fsSL https://raw.githubusercontent.com/bsaxon430/ghosty-vst/builds/install-plugins.sh | bash
2 · Or install by hand

Download one plugin from its card (or all of them), unzip, and drag the .vst3 into ~/Library/Audio/Plug-Ins/VST3. In Finder, press Cmd + Shift + G and paste that path. If macOS blocks it, run xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3.

3 · Rescan

FL Studio: Options › Manage plugins › Find more plugins. Ableton Live: Settings › Plug-Ins › Rescan.

Credits

Several plugins are built on open-source engines, including Vital, Surge XT, Six Sines, CDP8, PaulXStretch and Samplebrain. Each engine keeps its own licence, and full credits are on each plugin's About page.
