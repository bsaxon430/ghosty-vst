A wavetable synth plugin by Ghosty VST. Completely free and open source: no trial, no demo mode, no time limit, no account and no email needed. VST3 / AU / standalone for Mac and Windows.

Download for MacVST3 + AU + app · Apple Silicon & Intel · macOS 11+ · 10 MB Download for WindowsVST3 + app · Windows 10/11 64-bit · 6 MB

Each zip has the plugin, a standalone app, a one-click installer script and install notes. Source code (AGPL-3.0): github.com/bsaxon430/ghosty-vst.

What's inside

  • 81 presets: basses, leads, pads, keys, plucks and more
  • 2 wavetable oscillators with 16 shapes, plus draw your own wave
  • 4 filter types with drive and their own envelope
  • LFO (tempo-synced, 5 destinations), glide, mono and legato
  • Built-in drive, crush, chorus, phaser, echo and reverb
  • Scales, one-finger chords and an arpeggiator
  • Ghost XY pad and a slide-to-play keyboard strip
  • Save your own sounds; right-click any knob to type an exact value

Install

Mac: unzip, double-click Install Ghosty.command (if macOS blocks it: System Settings > Privacy & Security > Open Anyway), then rescan plug-ins in your DAW.
Windows: extract the zip, double-click Install Ghosty.bat and click Yes (if "Windows protected your PC" appears: More info > Run anyway), then rescan VST3 plug-ins.
FL Studio: Options > Manage plugins > Find more plugins. Ableton: Settings > Plug-Ins > Rescan. Logic: just reopen (uses the AU).
