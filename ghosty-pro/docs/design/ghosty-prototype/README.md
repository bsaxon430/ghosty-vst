# Ghosty prototype look (owner screen recording 2026-10-17) — visual language reference for Ghosty Pro

Owner (2026-10-25): "we used to have something like it. I liked how this looked overall visually. The UI will end up being very
Serum 2, very professional, but very GhostBlock, very fun."

What the prototype did (frames in this folder):
- Glowing neon lines: the wave display draws thick glowing strokes (green/cyan/purple) over a faint grid with ghosted earlier frames.
- A gentle neon 'rain' of particles (green / pink / cyan dots with trails) drifting down over the whole UI, low density, never in the way.
- Keyboard strip: FLOW / CHORD / ARP / HOLD toggles (lit green when on) and OCT - / + beside them; keys as dark colour-graded columns with
  note letters along the bottom.
- The ghost cursor on the keyboard: a tiny ghost that rides the finger/pointer, with speed lines when moving, an RGB-split glitch
  flicker, a sunglasses variant, and concentric ripple rings + particle burst where a key is played; a soft glow spot under him.
- Wave-shape palette of small thumbnails (sine, tri, saw, square, pulse, custom), one selected.
Design-reference only; recreate in our vector style with cheap animation (≤ 30 fps, no allocation in paint, toggle to turn ambient
effects off).
