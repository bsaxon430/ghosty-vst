# Phantom FX — third-party code

Phantom FX is licensed AGPL-3.0-or-later (see LICENSE). This file lists every outside project whose code is in the build,
with the exact SPDX identifier read from the LICENSE file in the cloned repo, the commit hash, and the files taken.
Rule: nothing is imported before its licence is read in the clone and recorded here. Licence texts live in `third_party/licenses/`.
Trademarked project names are credited here and in the About / Credits item only; never used as effect or feature names in the UI.

## Fonts and art
**Zen Maru Gothic** (Bold, Black) by The Zen Maru Gothic Project Authors, SIL Open Font License 1.1, from https://github.com/googlefonts/zen-marugothic (version 1.001): the typeface of the painted looks (DAWN, CEL). Bundled in the plugin as a Latin subset (letters, digits, punctuation, a few arrows; made with fontTools, no glyph changed); the font has no Reserved Font Name. Licence text: `assets/fonts/OFL-ZenMaruGothic.txt`, shipped in the Licenses folder.

**Inter** (ExtraBold, Black) by The Inter Project Authors, SIL Open Font License 1.1, from https://github.com/rsms/inter (version 4.000): the typeface of the NEON look. Bundled as a Latin subset inside the look's folder (`assets/looks/neon/fonts/`; made with fontTools, no glyph changed; no Reserved Font Name). Licence text: `assets/fonts/OFL-Inter.txt`, shipped in the Licenses folder. The Japanese on NEON's signs is part of the pictures (drawn by the designer with Noto Sans CJK JP and Zen Maru Gothic, both SIL OFL); no Japanese font ships.

The painted looks' art (`assets/looks/<look>/`: backgrounds, dials, buttons, tiles, ghosts, sprite strips) is GhostBlock's own, painted by code for Phantom FX (no third-party art, no image model, no existing film's designs). `tools/pack_look.py` packs the designer's export into those folders.

The UI look (colours, knob styles, logo art) is Brandon's own Ghost Box design, ported from his code (same repository, main branch, `ghosty-pro/Shared`).
